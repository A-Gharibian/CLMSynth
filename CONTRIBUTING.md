# Contributing

Public code contributions and issue tracking will open following the release of version **0.8.0**.

In the meantime, issue reports, improvement suggestions, and general inquiries can be sent directly to the maintainers
at the email address listed in [`CITATION.cff`](./CITATION.cff).

## Version to report

Issues are accepted only if they are found on the most recent commit of the program, 
issues found on the release version must first be checked with the latest commit before reporting.

## Using AI models to find and report issues

If you are using AI models to find issues, it is necessary to report the model used with it,
this is for tracking which models were already used, and to be able to trace, comment inline
or document issues that future runs should ignore.
